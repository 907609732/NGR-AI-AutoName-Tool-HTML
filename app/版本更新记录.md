## V2.7 - 临时测试 API 上传与翻译填入

更新日期：2026-06-02

更新类型：测试配置 / 翻译功能修复 / 命名编辑优化

### 更新内容

- 临时允许 `API配置文件/local-config.js` 上传 GitHub，方便其他电脑直接测试 Kimi 和百度翻译配置；OpenAI 配置因 GitHub Push Protection 保持留空。
- 独立配置文件新增 `NGR_LOCAL_KIMI_CONFIG`，保存 Kimi / Moonshot 视觉模型测试配置。
- “使用临时测试 API”优先读取 Kimi 配置；如果 Kimi 没有 Key，再回退到 OpenAI 配置。
- 百度翻译调用增加 JSONP 兜底，解决静态网页环境下浏览器 CORS 拦截导致点击后没反应的问题。
- 翻译侧边栏新增“填入最终名称”按钮，可把翻译结果直接写入当前选中图片的最终名称。

### 影响范围

- API 配置文件
- AI 接入测试流程
- 翻译侧边栏
- 待处理图片最终名称编辑

### 验证结果

- 百度翻译普通 fetch 失败时会自动尝试 JSONP。
- 翻译结果可写入当前选中图片的最终名称。
- API 配置仍保持在 `app/API配置文件/` 独立目录内。

## V2.6 - 命名质量与本地翻译增强

更新日期：2026-06-02

更新类型：命名质量优化 / AI 清洗 / 翻译能力增强

### 更新内容

- 本地命名词库补充 `卡片`、`卡带`、`卡`、`前往按钮`、`前往`、`装饰品` 等常见 UI 词。
- 方向识别优先处理 `左上角`、`右上角`、`左下角`、`右下角` 这类组合方向，避免被拆成单独的左右上下。
- AI 推荐名和本地推荐名统一清洗图片尺寸片段，禁止出现 `292x292`、`1024_512`、`w292_h292` 等分辨率命名。
- 相同语义候选在同一批命名中自动追加 `01`、`02`、`03` 序号，方便相似资源排序。
- 翻译设置新增 OpenAI 兼容文本模型配置，本地知识库命名可只发送文件名文本进行翻译，不上传图片。
- 本地翻译增加拼音兜底，字典和接口都处理不了的中文会转为 PascalCase 拼音。
- 中文含义字典补充 Go、Ornament、TopLeft、BottomRight 等词，减少推荐卡片里夹杂英文。

### 影响范围

- 本地知识库命名
- AI 推荐命名清洗
- 翻译侧边栏
- 命名单词中文含义展示

### 验证结果

- `前往按钮_常态` 可生成 `Go_Button_Normal`。
- `卡带_左上角` 可生成 `Card_TopLeft`。
- `装饰品_右下角` 可生成 `Ornament_BottomRight`。
- `Button_292x292` 会被清洗为 `Button`。
- 多张相同语义资源会自动追加两位序号。

## V2.1 - 大批量上传性能优化

更新日期：2026-06-01

更新类型：性能优化 / 稳定性提升

### 更新内容

- 上传流程改为分批处理，降低一次性读取大量文件造成的卡顿。
- 图片解析加入并发控制，避免浏览器瞬间占满资源。
- 待处理图片列表和检测结果列表改为分页式渲染。
- 图片预览对象 URL 改为懒创建，只为当前展示的列表项生成。
- 删除图片和清空列表时主动释放对象 URL，减少内存占用。
- 重复资源检测默认关闭，避免大批量上传时进行高成本比对。
- 超大批量图片自动跳过重复检测，优先保证页面可操作。

### 影响范围

- 图片上传
- 图片预览
- 列表渲染
- UI 切图检测
- 重复资源检测

### 验证结果

- 大批量上传时不再一开始就全量渲染。
- 页面交互压力明显下降。
- 万级图片场景具备继续优化基础。

## 版本维护约定

从 V2.2 起，每次改动后都要同步更新本文档。

小版本号递增规则：

- 修复 bug：小版本号 +1。
- 新增小功能：小版本号 +1。
- 明显影响多个模块的功能：小版本号 +1，并写清影响范围。
- 架构重构、重大能力升级：进入新的大版本或阶段版本。

文档记录原则：

- 不只写“修复若干问题”，要写清楚修了什么。
- 不只写“优化体验”，要写清楚优化在哪里。
- 涉及规则变化时，要写清楚旧规则和新规则差异。
- 涉及下载、图片处理、API Key、配置文件时，要写清楚安全影响。
